## 完成内容

Day 1 主要建立本地 API 调试入口，通过一份可直接在 HTTP 客户端中执行的请求示例，验证基础认证流程和健康状态。

### 调试变量

- `baseUrl`：默认 API 地址为 `http://127.0.0.1:9000`。
- `account`：调试账号，首次执行后如已存在可修改后重试。
- `password`：调试账号密码。
- `nickname`：注册时使用的昵称。

### 覆盖场景

- 健康检查：请求 `/health`，预期返回 `200`。
- 用户注册：请求 `/auth/register`，首次注册预期返回 `201`。
- 用户登录：请求 `/auth/login`，使用注册账号登录并获取 `access_token`，预期返回 `200`。
- 重复注册：使用已存在账号再次注册，预期返回 `409`。
- 错误密码登录：使用错误密码登录，预期返回 `401`。
- 缺少必填字段：注册请求省略 `nickname`，预期返回 `400`。

## 使用方式

1. 启动 API 服务并确认监听地址与 `baseUrl` 一致。
2. 按顺序执行健康检查、注册和登录请求。
3. 根据需要执行重复注册、错误密码和缺少字段请求，检查错误响应是否符合预期。
