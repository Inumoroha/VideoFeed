## 用户资料

- 扩展用户领域模型，加入头像、简介和用户状态，并补充资料更新、按 ID 查询及对应错误定义。
- 完善用户仓储的资料字段持久化、参数校验和 SQL Mock 测试。
- 增加用户资料应用服务，实现资料查询、更新和注册结果映射，并补充应用层测试。

- 统一用户 API 路由，给受保护接口接入 JWT 鉴权，并同步 OpenAPI、调试请求和路由测试。

## 视频能力

- 建立视频领域模型，实现发布、查询、删除、标题长度校验和领域错误定义。
- 增加视频 PostgreSQL 模型与仓储，覆盖分页查询、参数校验、删除和 SQL Mock 测试。
- 实现视频应用服务，支持发布、查询、列表、删除和幂等创建，并处理仓储异常。
- 增加视频 HTTP Handler，完善请求校验、认证、错误响应和接口测试。
- 注册视频路由，启动时迁移视频表，并补充视频接口流程测试。
- 增加 `description` 字段，打通领域模型、持久化、Feed 查询、接口响应、迁移、OpenAPI、测试和模块文档。

## Feed 信息流

- 建立时间线视频项、分页游标和观看事件领域模型，增加身份、事件类型、时长、幂等键和游标校验。
- 增加 Feed PostgreSQL 仓储，实现时间线查询、游标分页、参数校验和观看事件幂等冲突处理。
- 在应用服务中修复 lookahead 分页、下一页游标生成、分页边界、初始化校验和错误映射。
- 增加可选 JWT 中间件：访客可继续访问公开流程，有效令牌会写入用户 ID，无效令牌会被拒绝。
- 增加 Feed Handler、路由和完整流程测试，统一时间线入口为 `/api/feed/timeline`，并移除已删除的旧观看事件路由。
- 重构领域模型及仓储契约后，同步适配持久化、应用服务、Handler、路由、测试、OpenAPI 和模块说明。
- 增加持久化分页游标的保存、有效期校验及旧版 Base64 游标兼容和迁移测试。

## 文件上传

- 增加上传 Handler，实现上传根目录、请求大小限制、扩展名规范化和安全校验。
- 补充上传处理器测试、上传路由、静态文件目录、鉴权测试和 OpenAPI 定义。
- 修复上传处理器参数变更引起的路由注册与测试编译问题，并统一文件保存及静态访问目录。
