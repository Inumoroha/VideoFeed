- 将互动能力接入 React/Vite Feed，支持操作反馈、评论抽屉、评论发布与服务端统计刷新。

## 视频统计与权限

- 将 `like_count`、`comment_count` 和 `favorite_count` 拆分到 `video_stat` 表，视频创建时在同一事务中初始化统计记录。
- 适配视频详情、作品列表和 Feed 查询，使其统一读取视频统计数据。
- 在 JWT 上下文中增加管理员角色，为评论删除等需要角色判断的操作提供权限依据。

## 互动能力

- 新增互动领域模型，定义点赞、收藏动作与评论对象，并实现动作类型规范化、状态判断和评论内容校验。
- 新增 `interaction_action`、`interaction_action_idempotency` 与 `interaction_comment` 持久化模型及仓储。
- 在事务中更新评论和互动动作，同时维护 `video_stat` 中的点赞、收藏、评论计数。
- 增加互动应用服务，处理点赞、收藏切换、评论创建、评论列表分页和评论删除用例。
- 为点赞、收藏和评论请求提供幂等支持，持久化首次执行的状态与统计快照，避免重试造成重复计数。
- 增加互动 HTTP Handler 与路由：`POST /api/interactions/like`、`POST /api/interactions/favorite`、`GET/POST /api/comments`、`DELETE /api/comments/{commentId}`。
- 评论列表保持公开访问；创建、删除评论以及点赞、收藏均要求 JWT 鉴权，删除操作校验作者或管理员权限。

## Web 前端

- 在 Feed 页面接入点赞、收藏和评论接口，使用服务端返回的互动统计刷新界面，避免前端重复累加。
- 增加评论抽屉，覆盖加载、空列表、请求失败、重试、未登录限制和发表评论状态。
- 支持键盘、滚轮和触控拖拽切换视频，保持视频浏览操作在桌面端和触控设备上的可用性。
